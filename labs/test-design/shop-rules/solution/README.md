# 해설 — 쇼핑몰 규칙으로 테스트 케이스 설계하기

> 스포일러입니다. 직접 풀어 본 뒤에 읽으세요. 숨은 결함의 내용은 이 문서에 적지 않습니다(채점 결과의 `[검출]` 행이 어떤 케이스가 결함을 드러냈는지 보여 줍니다).

이 폴더의 CSV는 **하나의 모범 답안**입니다. 같은 결함을 잡는 다른 설계도 정답입니다.

## 설계 포인트
- **t1**: 등급 경계 3개(100,000 · 500,000 · 1,000,000)마다 "바로 아래 · 정확히" 두 점, 거기에 최솟값과 무효 구간(음수)을 더해 8개입니다. "바로 위"는 다음 경계의 아래쪽 동등 분할과 겹치므로 줄였습니다.
- **t2**: 배송비는 **할인 후 금액**으로 판단하므로, 등급 할인이 있는 회원으로도 경계를 시험합니다(`lee` 행). 도서산간 추가 운임은 무료 배송과 **독립된 조건**이라 두 조합을 모두 둡니다. 수량은 0 · 1 · 99 · 100.
- **t3**: 조건은 ① 쿠폰 종류 ② 최소 주문 금액 충족 ③ 등급 할인 유무 ④ 최대 할인액 초과 ⑤ 유효 기간입니다. 모든 조합(2⁵)을 만들지 않고, **결과가 달라지는 규칙**마다 한 열(=한 행)씩 남겼습니다.
- **t4**: 상태 × 동작 표를 그리고, 허용된 전이마다 하나, **허용되지 않은 전이** 중 위험한 것(출고 후 취소, 결제 전 출고, 취소 후 결제)을 하나씩, 환불 기한의 경계(7일 · 8일)를 더했습니다.
