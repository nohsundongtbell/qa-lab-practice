# 정률 쿠폰(SALE10)의 최대 할인액 5,000원이 적용되지 않아 8,900원이 할인된다

- 심각도: S2
- 우선순위: P1
- 발견 환경: QA 숍 로컬, 결함 프로필 beginner, 2026-10-03, Windows 11 / Edge 140
- 관련 사양: SPEC §4 쿠폰 — 정률 쿠폰

## 재현 절차
1. `kim@example.com` 으로 로그인한다.
2. 모니터 암(상품 6번, 89,000원) 1개를 장바구니에 담는다.
3. 쿠폰 `SALE10`(10%, 최대 5,000원, 최소 30,000원)을 고르고 결제 금액을 본다.

```repro
steps:
  - login: kim@example.com
  - quote: { items: [{ product: 6, qty: 1 }], coupon: SALE10 }
    expect: { status: 200, json: { couponDiscount: 5000, total: 84000 } }
```

## 기대 결과
SPEC §4 "⌊subtotal × rate%⌋ 할인. 단 최대 할인액 maxDiscount원을 넘지 않는다" → 8,900원이 아니라 5,000원 할인, 결제 금액 84,000원.

## 실제 결과
쿠폰 할인 8,900원, 결제 금액 80,100원. 할인 대상 금액이 50,000원을 넘는 모든 주문에서 상한이 무시된다.

## 심각도·우선순위 근거
- 심각도 S2: 금액이 틀리게 계산되고, 고가 주문일수록 회사 손실이 커진다(예: 459,000원 → 45,900원 할인).
- 우선순위 P1: 쿠폰이 발급된 모든 회원이 지금 쓸 수 있다. 쿠폰을 일시 중지하거나 즉시 고친다.

## 증거
- `POST /api/quote` 응답: `{"subtotal":89000,"couponDiscount":8900,"total":80100,…}`
