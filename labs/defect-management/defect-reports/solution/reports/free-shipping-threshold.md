# 할인 후 금액이 정확히 50,000원이면 무료 배송이 적용되지 않고 배송비 3,000원이 붙는다

- 심각도: S3
- 우선순위: P2
- 발견 환경: QA 숍 로컬, 결함 프로필 beginner, 2026-10-03, macOS 15 / Chrome 140
- 관련 사양: SPEC §5 배송비

## 재현 절차
1. `kim@example.com` / `qa-lab-1234` 로 로그인한다 (NORMAL 등급, 등급 할인 0%).
2. 무선 키보드(상품 1번, 50,000원) 1개를 장바구니에 담는다.
3. 장바구니에서 결제 금액을 확인한다 (쿠폰 사용 안 함).

```repro
steps:
  - login: kim@example.com
  - quote: { items: [{ product: 1, qty: 1 }] }
    expect: { status: 200, json: { subtotal: 50000, shippingFee: 0, total: 50000 } }
```

## 기대 결과
SPEC §5 "할인 후 금액이 **50,000원 이상**이면 기본 배송비 0원" → 배송비 0원, 결제 금액 50,000원.

## 실제 결과
배송비 3,000원, 결제 금액 53,000원. 50,001원(상품 1번 + 9번 1개는 51,000원)에서는 배송비가 0원이므로 **정확히 50,000원**에서만 틀린다.

## 심각도·우선순위 근거
- 심각도 S3: 금액이 틀리지만 정확히 경계 금액일 때만 생기고, 상품을 하나 더 담으면 피할 수 있다.
- 우선순위 P2: "5만 원 이상 무료 배송"은 프로모션 문구로 노출되는 규칙이라 고객 문의로 이어지기 쉽다. 다음 배포 전에 고친다.

## 증거
- `POST /api/quote` 응답: `{"subtotal":50000,"gradeDiscount":0,"couponDiscount":0,"totalDiscount":0,"shippingFee":3000,"total":53000,…}`
- 응답 헤더 `X-Request-Id`: (재현할 때 기록)
