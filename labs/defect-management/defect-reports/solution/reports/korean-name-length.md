# 한글 이름이 7자 이상이면 "2자 이상 20자 이하" 오류로 회원 가입이 거절된다

- 심각도: S2
- 우선순위: P1
- 발견 환경: QA 숍 로컬, 결함 프로필 beginner, 2026-10-03, macOS 15 / Chrome 140
- 관련 사양: SPEC §1.1 회원 가입 — 이름

## 재현 절차
1. 회원 가입 화면을 연다.
2. 이름에 `김수한무거북이와두루미`(11자), 이메일 `long-name@example.com`, 비밀번호 `password123`, 우편번호 `06236` 을 넣고 가입한다.

```repro
steps:
  - signup: { name: 김수한무거북이와두루미, email: long-name@example.com, zipcode: '06236' }
    expect: { status: 201, json: { name: 김수한무거북이와두루미 } }
```

## 기대 결과
SPEC §1.1 "앞뒤 공백을 제거한 뒤 2자 이상 20자 이하. 글자 수는 사람이 보는 글자 단위(한글 1글자 = 1자)" → 11자는 가입되어야 한다(201).

## 실제 결과
`400 VALIDATION_ERROR`, `details.fields.name`: "이름은 2자 이상 20자 이하여야 합니다." 6자는 가입되고 7자부터 거절된다. 영문 11자(`Abcdefghijk`)는 가입된다 → 글자 수가 아니라 바이트 수로 세는 것으로 보인다.

## 심각도·우선순위 근거
- 심각도 S2: 핵심 흐름(가입)이 **한글 이름이 긴 사용자 전체**에게 막히고 우회할 방법이 없다(이름을 줄여 가입하면 실명과 달라진다).
- 우선순위 P1: 신규 가입이 막혀 매출에 직접 영향을 준다. 즉시 고친다.

## 증거
- 응답: `{"code":"VALIDATION_ERROR","message":"입력값을 확인해 주세요.","details":{"fields":{"name":"이름은 2자 이상 20자 이하여야 합니다."}}}`
- 6자 `김수한무거북` → 201, 7자 `김수한무거북이` → 400
