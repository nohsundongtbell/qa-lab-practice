# 해설 — 결함 지도

> 스포일러입니다. 탐색을 마친 뒤에 읽으세요.

`intermediate` 프로필에는 결함이 12개 있습니다. 아래 "결함 지도"는 **어떤 탐색 방향이 어떤 종류의 결함으로 이어지는지**를 보여 줍니다. 결함의 정확한 내용은 모범 세션 노트(`sessions/`)를 보세요.

| 탐색 방향 | 관련 휴리스틱 | 모범 노트 | 찾을 수 있는 결함 종류 |
|---|---|---|---|
| 상태 전이 표의 허용되지 않은 칸 | 상태와 전이 발견 | session-1 버그 1 | 잘못 허용된 전이 |
| 동작 **뒤에 남는** 데이터 (재고) | 데이터 따라가기, CRUD | session-1 버그 2 | 되돌려지지 않는 데이터 |
| 화면 값 vs **저장된** 값 | UI 없이 탐험하기 | session-2 버그 1 | 저장 값 정합성 |
| 같은 자원을 **두 번** 쓰기 | 순서·반복 바꾸기 | session-2 버그 2 | 한 번만 써야 하는 자원의 재사용 |
| **누가** 하느냐 (등급) | 숨은 변수, 퍼소나 | session-2 버그 3 | 특정 회원에게만 생기는 계산 오차 |
| 상한·하한 | 경계 | session-2 버그 4 | 상한 미적용 |
| **언제** 하느냐 (시각·시간대) | 숨은 변수 | session-3 버그 1 | 시간대 혼동 |

모범 노트에 없는 결함(경계 배송비, 경계 등급, 쿠폰 최소 금액 판단, 수량 0, 한글 이름 길이)은 `beginner` 프로필에서도 보이는 **표면** 결함입니다. 랩 1·2에서 다룹니다.

## 세션 노트를 볼 때
- **테스트 노트**에 실패한 시도와 "정상이었다"는 관찰도 남겼습니다. 다음 사람이 같은 곳을 반복하지 않게 하기 위해서입니다.
- 버그를 찾으면 **범위를 좁히는 관찰**을 덧붙였습니다. 예: "정률 쿠폰은 막히고 정액 쿠폰만 문제", "환불 경로는 정상이고 취소 경로만 문제".
- 확신이 없는 것은 버그가 아니라 **이슈·질문**에 적었습니다.
