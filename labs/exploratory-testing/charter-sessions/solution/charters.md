# 탐색 차터

## 차터 1
- 탐험 대상: 주문 상태 변화와 취소·환불
- 자원: kim·admin 계정, SPEC §7 상태 전이 표, API 문서(/docs), 상품 목록의 재고 값
- 알아낼 정보: 허용되지 않은 전이가 막히는지, 취소·환불 뒤 재고·쿠폰·누적 구매액이 사양대로 되돌아가는지
- 리스크: 출고된 물건이 취소되거나 재고가 틀리면 물류·금전 손실과 판매 기회 손실이 생긴다

## 차터 2
- 탐험 대상: 할인 금액 계산과 저장된 주문 금액
- 자원: 등급이 다른 회원 5명, 쿠폰 6종, SPEC §3·§4, 금액 미리보기와 주문 상세 API
- 알아낼 정보: 미리보기·주문 응답·저장된 금액이 서로 같고 사양과 맞는지, 쿠폰이 한 번만 쓰이는지
- 리스크: 할인 오류는 곧 회사 손실이나 고객 불만이고, 저장된 금액이 틀리면 정산 전체가 틀린다

## 차터 3
- 탐험 대상: 배송 예정일 (결제 시각·휴일·도서산간)
- 자원: delivery-estimate API, SPEC §6 휴일 표, 시간대가 다른 결제 시각 목록
- 알아낼 정보: 출고 마감 시각, 주말·휴일, 도서산간 조합에서 날짜가 사양과 맞는지
- 리스크: 화면에 약속한 도착일을 못 지키면 문의·취소가 늘고 신뢰가 떨어진다
